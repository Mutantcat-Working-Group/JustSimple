```xml
<dependency>
    <groupId>org.noear</groupId>
    <artifactId>justsimple-banner</artifactId>
</dependency>
```

#### 1.Description

A plugin to add banner as JustSimple App start.

#### 2.Configuration

```yml
#By default the banner is true
justsimple.banner.enable: true
#Where to print the banner , values console/log/both
justsimple.banner.mode: "console"
#Path to banner resource file
justsimple.banner.path: "banner.txt"

```
